# Inbox processing session (distilled import)

Use this for a **single sitting** after import. Pair with [inbox-triage-after-import.md](inbox-triage-after-import.md) for rules and promotion checklist.

## Pick a scope

Choose **one** of:

- **Theme:** e.g. `grep` inbox for `distilled-useful-knowledge-music` or open files matching a tag you will add later; or pick one subdirectory pattern (`distilled-how-to-*` about Phoenix).
- **Count:** **10–20** notes for a deep pass; up to **~50** only if you are mostly purging or quick-moving without rewriting.

Write the theme or file list at the top of your daily note or here before you start.

## Session checklist

1. **Graphify (optional start):** `brain-graph` if the vault has moved a lot since last index.
2. **Per note** (repeat until batch done):
   - Open next inbox file from your scope.
   - Follow the **promotion checklist** in [inbox-triage-after-import.md](inbox-triage-after-import.md) (fold Distilled content, YAML, tags, rename, move).
3. **End of session:** `brain-graph` then `brain-save` (or your git workflow).

## Quick per-note order (suggested)

1. Read once; decide: **keep / merge / purge**.
2. If keep: edit in place or **move** to target folder with **rename** in one step (fewer broken links if you use Obsidian rename).
3. If merge: edit canonical note first, then delete or stub the duplicate.
4. If purge: `90-Archive/` or delete per your comfort.

## Stop rule

When you hit **fatigue** or **end of chosen theme/count**, stop—even if Inbox is not empty. The next session picks a new scope.
